# Security

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository. Don't open a public issue for security problems.

The Reader makes network requests only to fetch Catalogues you add (and the two it ships with) and to
download Books. It has no accounts, no telemetry, and no server of its own (ADR 0003). Reports about data
leaving the phone in any other way are especially welcome.
